# base-ui-toc

An unstyled Table of Contents component. Built for being used alongside [BaseUI](https://base-ui.com) in React 19 projects. Made to be highly portable.

Copy the file into your repository, read it, and change it to match your team's standards and goals.

## Usage

### 1. Install dependencies

```bash
npm install @base-ui/react @base-ui/utils
```

```bash
pnpm add @base-ui/react @base-ui/utils
```

```bash
bun add @base-ui/react @base-ui/utils
```

### 2. Copy and paste the following code into your project

[src/table-of-contents.tsx](./src/table-of-contents.tsx)
